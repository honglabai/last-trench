# 01. 최후의 참호 — Game Design Document (GDD)

**프로젝트:** LAST TRENCH / 최후의 참호  
**버전:** GDD 1.0 (2026-11-13)  
**상태:** 21개 인터뷰 확정안 통합. 세부 수치는 검증 전 초기 제안값.

## 1. 게임 비전과 디자인 원칙

**한 줄 정의:** 현대 드론전과 참호전을 배경으로, 병사 한 명을 3인칭으로 직접 조작하면서 지정된 진지에 방어시설을 설치·수리하고 15단계 공세를 버텨내는 **모바일 전술형 로그라이크 디펜스**.

**핵심 재미 4가지**
1. **생존:** 드론·보병·화력 위협을 피하고 조준·사격으로 직접 대응하는 TPS 손맛.
2. **우선순위:** 탄약·시설 수리와 무기 구매 사이에서 크레딧·보급 자원의 사용을 결정.
3. **상황 변화:** 포격, 전자전, 야간, 기상, 복합 공세가 만드는 인지·대응의 긴장감.
4. **회차별 빌드:** 매 웨이브 강화 카드 3장 중 1장을 택해 다른 전투 스타일을 구성.

폭력 표현은 **비잔혹적 게임 연출**로 제한한다. 게임 적은 가상의 군사 세력으로 설정하고 실제 분쟁의 희생자를 직접 재현하지 않는다. 실제 군사 운용법/무기 제작법이 아닌 게임의 추상화된 행동·수치로 구현한다.

## 2. 타깃, 장르, 기기

- **플랫폼:** Android 우선, Google Play 다음 iOS, 그 후 PC.
- **입력:** 모바일 가로 고정/두 손 터치. 좌측 가상 스틱, 우측 시야/조준·사격, 배치된 버튼. 수동 조작 또는 선택형 자동 보조.
- **카메라:** 기본은 넓은 3인칭, ADS(조준) 시 어깨너머 카메라로 부드럽게 전환. 과도한 카메라 흔들림 방지.
- **그래픽:** 모바일 최적화 경량 3D; 초기에는 GDScript로 단순 프리미티브 메시를 생성하고 향후 교체.
- **연출:** 총구 섬광·탄착·폭발·포연·드론 격파·포격 경보, 상황별 효과음과 배경음악, 과도한 유혈 없음.
- **성능 목표:** 중급형 Android에서 안정적 30FPS, 동시에 살아 있는 적 **10~15개 범위**. 실기기 검증 필요.

## 3. 게임 모드

### 3.1 모드 A — 개활지 전투

- 메인 메뉴에서 **독립적으로 선택**. 참호 모드에서 실시간 이동하여 전환하지 않는다.
- 구릉·도로·폐허·간이 엄폐 등을 활용한 열린 지형, 전방 방어 목표물 보호.
- 공격은 정면 중심의 출현 영역에서 시작하고, 돌격 경로나 전방 측면 경로가 변주된다.
- 플레이어 자유 이동·직접 교전, 지정된 방어시설 슬롯, 부분 파손 엄폐를 공통 엔진으로 구현.
- 초기 MVP는 제외하며 정식 확장 단계에서 참호 공통 자산을 활용해 구현.

### 3.2 모드 B — 참호 방어

- 최초 구현 대상. 지그재그 참호, 사격 위치, 연결 통로, 모래주머니, 거점 깃발/통신 장비를 추상화한 방어 대상.
- 지상 적은 전방에서 접근하고, 공중 적은 **전방 상공**에서 접근. 360도 스폰 금지.
- 플레이어가 지정 슬롯에 접근하면 **설치·수리** UI 노출. 주무기로 직접 전투하면서 자동 포탑을 지원.
- 후반부에 포격/재밍/비·먼지 등 전장 상황 변화를 이벤트로 추가.

### 3.3 맵 확장 원칙

모드별 첫 맵 1개(총 2개)를 완료한 후, 같은 데이터 및 씬 계약을 유지한 채 추가 맵을 확장한다. 무작위 지형 전체 생성은 기본 요구가 아니다.

## 4. 전투 1회(런) 구조

**목표:** 15웨이브 20~30분, 5/10/15웨이브 보스 또는 특수 공세.

```text
메인 메뉴 → 이어하기 / 신규 출격 → 모드·난이도·장비 선택
→ 웨이브 준비(배치/보급) → 적 출현 → 실시간 전투
→ 웨이브 종료 → 크레딧 획득 → 강화 카드 3개 중 1개 선택
→ 상태/자원/장비/부활 잔여량 체크포인트 저장
→ 다음 웨이브 ... → 15웨이브 승리 → 상세 결과 → 메인 메뉴
                         ↘ 병사 1차 사망: 즉시 부활
                         ↘ 재사망 또는 거점 파괴/점령: 패배 → 결과
```

**예외:** 앱이 전투 도중 중단되면 마지막으로 **커밋 완료된 웨이브 경계 체크포인트**에서 복구한다. 재접속으로 자원·강화 선택을 중복 수령할 수 없게 상태 전이를 원자적으로 관리한다. 게임이 패배 확정되면 진행 체크포인트는 정리(또는 게임오버 플래그로 무효화)하고 기록만 저장한다.

## 5. 웨이브 상세 구성 — 제안 초기 콘텐츠

아래는 **확정된 5/10/15 보스 구조**를 구현하기 위한 초기 배치안이다. 적 수·타이밍·체력은 밸런스 테스트 후 수정한다.

| 웨이브 | 위협 구성 초안 | 변화/학습 포인트 | 특별 요소 |
|---|---|---|---|
| 1 | 보병 | 이동·사격·엄폐 | 튜토리얼급 |
| 2 | 보병 + 소수 공격 드론 | 고도별 조준 | 기본 포탑 소개 |
| 3 | 보병 + 드론 | 수리·보급·자원 사용 | **MVP1 종료점** |
| 4 | 빠른 돌격병/소수 RPG | 표적 우선순위 | 준비 단계 확대 |
| 5 | 드론 군집 지휘체(공중 보스) | 군집 패턴 읽기 | 보스 1 |
| 6 | 보병 + 드론 + 엄폐 파괴 | 수리 우선순위 | 파괴 이벤트 |
| 7 | 전투로봇 + 보병 | 내구도 다른 적 | 고내구 적 |
| 8 | 적 정찰 + GPS 재밍 | HUD 제한 대응 | 전자전 이벤트 |
| 9 | 보병 + 야간 드론 | 시야·탐지 대응 | 야간/먼지 |
| 10 | 중장갑 전투로봇(보스) | 강공격 예고·회피 | 보스 2 |
| 11 | RPG + 보병 + 드론 | 복합 방어 | 공격 빈도 증가 |
| 12 | 야포 경보 + 지상 공격 | 엄폐·이동 | 포격 구역 경보 |
| 13 | 헬기/항공 지원 위협 | 공중 위험 경보 | 비·안개 변주 |
| 14 | 방사포 공세 + 돌격 | 제한 자원/수리 | 고난도 보급 |
| 15 | 최종 복합 공격(군집·지상·포격·헬기 중 조합) | 모든 기술의 종합 | 보스 3/최종 승리 |

적 유형은 **게임 내 역할**로 추상화한다. 야포·방사포·전투기는 필요에 따라 **경고·타격 구역을 갖는 이벤트형 위협**이며, 매번 AI 비행체/포병 오브젝트를 직접 시뮬레이션해야 하는 것은 아니다. 드론·보병·전투로봇·RPG 병사·헬기 등은 콘텐츠 확장 순서에 따라 구현한다.

**적응형 AI — 중간 수준:** 현재 웨이브 구간/난이도/플레이어 실적/시설 상태를 입력받아 사전에 정의된 적 조합과 생성 빈도를 한정된 범위에서 조정한다. 웨이브 5/10/15 보스 출현과 정면 중심 출현은 고정. 플레이어에게 매번 회피 불가능한 공격을 가하지 않으며, 동일한 시드와 상태라면 재현 가능하게 한다.

## 6. 플레이어·생존·조작

### 6.1 플레이어 전투 기능

- 이동(앞/뒤/좌/우), 카메라 회전, 넓은 기본 시야 ↔ ADS 어깨너머 전환.
- 주무기 사격, 조준, 재장전, 무기 전환(완성형). MVP는 소총 1종.
- 피격/사망과 즉시 부활 **게임당 1회**. 최초 사망은 최대 체력의 제안 비율로 복구하고, 짧은 무적 시간 부여(플레이 테스트로 조정). 두 번째 사망 즉시 패배.
- 거점 체력 0 또는 점령 조건 충족 시 **부활 잔여량과 관계없이 패배**. 이는 이전 '복합형 패배' 규칙을 명확히 구현한 것.
- 공격 가시성을 위해 크로스헤어와 피격 방향 경고, 탄약, 재장전, 무기 상태를 표시.

### 6.2 보조 조작 옵션

- 왼쪽 가상 조이스틱 이동, 오른쪽 화면 영역 카메라 회전, 조준·사격·재장전·설치 버튼.
- 설정에서 조준 보조 강도 조절(꺼짐/약함/강함 등 **제안 등급**); 강함도 100% 자동 명중으로 만들지 않는다.
- 혼합형 자동화(예: 재장전 보조, 타깃 감지 보조)는 각각 사용자가 선택. 보조 없더라도 모든 전투 가능.
- HUD 버튼 위치/크기 변경, 화면 흔들림/진동 축소, 색상 구분/폰트 크기 변경. 터치 안전 영역(노치·제스처 영역) 고려.

## 7. 무기·장비 카테고리 — 최종 콘텐츠

| 계열 | 게임 내 역할 | 해금·제어 |
|---|---|---|
| 소총·기관총 | 기본 범용 지상 표적 | MVP 소총 1종, 이후 업그레이드 |
| 저격총·DMR | 장거리 단발 고화력 | 전투 크레딧/해금 |
| 유탄·로켓 | 범위 피해·강적 압박 | 느린 발사/탄약 제약 |
| 대드론 무기 | 공중 표적 대응 | 이동 표적 보정·탄약 제약 |
| 고정형 방어시설 | 지정 슬롯의 자동 방어 | 보급 자원 설치·수리 |
| 전자전·특수장비 | 탐지/재밍 대응, HUD 회복 | 지속시간·쿨다운 |
| 드론·화력지원 | 정찰·일시 지원 | 임무 보조/쿨다운 |

적과 장비를 실제 무기의 구체적 성능표로 재현하는 것이 아니라 **게임 플레이 수치**로 추상화한다.

## 8. 방어시설·엄폐 시스템

- **지정된 슬롯**에만 설치 가능(`DefenseSlot`이 배치 가능 여부 제공). 슬롯 근접 범위에 들어오면 '설치' 또는 '수리' 액션을 표시. 멀리서 자유 배치 불가.
- MVP 기본 시설은 **고정 기관총 포탑** 1종. 초기 목표는 자동 표적 선정, 체력, 쿨다운, 파손, 수리, 강화 연결.
- 방어시설과 파괴 가능 엄폐물은 개념을 분리한다: 포탑은 설치/수리/강화가 가능하고, 모래주머니 등은 수리할 수 있으나 설치 가능 슬롯 규칙을 위반하면 안 된다.
- 부분 파괴는 지정된 엄폐/방어물의 손상 상태 변환에 한정. 지형 전체를 지형편집기로 파괴하는 시스템은 범위 밖.

## 9. 경제·성장·해금

### 9.1 이중 자원 (확정)

- **Credits/크레딧:** 적 처치·웨이브 완료 시 획득, 무기 구매·강화에 사용.
- **Supplies/보급 자원:** 시작 보급·웨이브 일부 보급·보급 이벤트로 획득, 탄약/수리/방어시설에 사용.
- **무기 강화 카드:** 각 웨이브 종료 시 겹치지 않는 유효 후보 3개를 생성하여 **1개 선택**. 카드 풀에 유효 카드가 3개 미만이면 명시된 대체 보상 제공.
- **추가 크레딧:** 카드 1장 선택 후 동일 웨이브 보상 처리에서 함께 지급. 중복 지급 방지를 위해 완료 ID 사용.

### 9.2 진행 시스템

- 기본 장비는 특정 웨이브 도달로 사용 가능; 특별 장비는 업적/보스 격파로 해금. 해금 조건은 데이터로 관리.
- **영구:** 장비 해금, 업적, 최고 기록, 설정값.
- **회차 한정:** 크레딧·보급 자원, 임시 강화, 부활 사용 여부, 파손된 시설 상태, 현재 웨이브.
- 플레이 시작 시 회차 자원을 새로 지급. 저장된 도전의 이어하기는 이전 회차의 자원·상태를 복원.

### 9.3 수익화 분리

무료 배포 + 사용자가 요청한 **보상형 광고**. 광고 없이 전투와 해금이 가능해야 하며, 오프라인에서도 기본 시스템이 정상 동작. 광고 실패/취소/오프라인 시 아무런 손실이나 진행 차단이 없다. 광고 기능은 MVP 제외, 출시 전 호환 Godot Android 플러그인 별도 검증. 광고 보상은 진행 우위가 과도하지 않은 선택적 회차 보상으로 제안하며, 정확한 보상량·노출 한도는 이후 밸런스 테스트에서 승인.

## 10. 난이도·밸런스

- **쉬움·보통·어려움** 세 단계.
- 웨이브 상승은 단순 체력 곱셈만이 아니라 **적 구성·위협·공격 빈도**의 단계적 상승.
- 부활 1회는 세 난이도에서 동일(질문 17 확정).
- 자원 관리 + 일부 웨이브 후 보급 및 회복. 재화가 부족해 진행이 불가능한 데드락을 방지할 최소 보급 규칙 필요.
- 5/10/15의 고정 보스는 외부 난수에도 변하지 않음. 화면에 위험 경보를 제공해 대응 가능한 전투를 유지.
- 테스트 지표: 난이도별 완료율, 실패 웨이브 분포, 평균 플레이 시간, 부활 사용 시점, 필수 무기 편중도, 방어시설 이용률, FPS.
- `config_examples/balance_v0.json`은 **제안 초기값**이다. 난이도 계수·무기 수치를 코드 곳곳에 하드코딩하지 않는다.

## 11. 게임 화면 및 UI

**메인 메뉴:** 게임 시작 / 이어하기(체크포인트 있을 때만 활성) / 장비고 / 업적 / 전투 기록 / 설정.

**출격 준비:** 모드 선택, 쉬움·보통·어려움, 해금된 주무기·보조장비 선택, 출격 버튼. 미구현 콘텐츠는 잠금 상태와 개발 단계 상태를 구분하여 표시.

**전투 표준 HUD:** 플레이어 체력·탄약·사격/조준 버튼·웨이브, 거점 체력, 크레딧·보급 자원, 방어시설 상태, 적 경보, 일시정지. 미니맵은 미래 고급 기능(기본 요구 아님).

**결과 화면:** 승패, 도달 웨이브, 플레이 시간, 적 처치, 사격 수/명중률, 피해량, 시설 기여도, 보스 처치, 최고 기록. 지표를 누락 없이 수집하되 **초기 MVP는 구현 가능한 값부터 점진적으로 표시**.

**스타일:** 어두운 밀리터리 색상 + 현대 디지털 전장 표시. 그래픽·프레임, 효과음·BGM·진동, 조작 버튼 크기/위치, 언어(한국어/영어), 글씨 크기, 화면 흔들림/색상 구분을 설정에서 제공.

## 12. 저장·중단·이어하기

- 자동 저장은 **웨이브 종료 후 보상 결산과 카드 선택까지 완료한 안전 지점**에서 새 스냅샷으로 생성.
- 저장 시 현재 게임 상태, 난이도·모드·장비·자원·부활 사용 여부·웨이브 커서·시설 상태·랜덤 시드/상태를 구조화.
- 앱 재실행 시 '이어하기' 또는 '포기' 제시. 포기는 활성 런 저장을 지우되 영구 장비 해금/기록은 남김.
- 일시정지는 앱 백그라운드로 진입했을 때 입력을 잠그고 오디오를 조절. *웨이브 중단 위치에서 정확히 이어하기*는 확정 요구가 아니다. 체크포인트 복구 규칙을 안내한다.
- 저장 버전(`schema_version`), 유효성 검사, 파일 교체 중 오류 대응, 부정/손상 데이터에 대한 안전 초기화 필요.

## 14. 성공 기준(검증 계획)

- MVP1: 실제 Android에서 3웨이브 플레이, 지상/공중 적 구분, 슬롯 설치·수리, 플레이어 1회 자동 부활, 거점 파괴/전사 패배, 3웨이브 격퇴 승리, 재실행/가로 화면/터치 확인.
- MVP2: 보급·크레딧 정산 정확, 카드 1장만 적용, 앱 강제 종료 후 마지막 안전 체크포인트부터 회복, 해금 영구 유지/회차 재화 초기화.
- 완성형: 두 독립 모드 모두 15웨이브 완료 경로, 5/10/15 보스와 특수 이벤트, 세 난이도, 한국어·영어, 상세 기록.
- 출시: 중급 Android 대표 기종에서 30FPS 목표 실제 검증, 필수 기능 회귀 테스트 통과, 오프라인 정상 사용, 광고 시청 선택/실패/취소 검증, 스토어 심사 요구사항 확인.

## 15. 추가 결정이 필요한 것이 아니라 '검증해야 할' 값

정확한 체력·대미지·가격·시간·보급량, 참호 실측 크기, 장비별 쿨다운, 적 스폰 간격, 완료율 목표, 기기 모델별 안정적 FPS는 **개발 시 기본값으로 시작하고 플레이 테스트를 통해 조정**. 확정 게임 요구사항을 임의 변경하지 않는다.
